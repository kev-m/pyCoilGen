# Glossary

stl
: A [file format for stereolithography CAD files](https://en.wikipedia.org/wiki/STL_(file_format)) that describes a
triangulated surface consisting of facets and vertices.

Gradient Field
: A magnetic field in the target volume that has a [specific gradient](https://mriquestions.com/gradient-coils.html).

Target Field
: A desired vector field in the desired target volume.

Gerber
: A [file format](https://en.wikipedia.org/wiki/Gerber_format) (RS-274X) for the copper layers of printed circuit boards.

Biot-Savart Law
: The [law](https://en.wikipedia.org/wiki/Biot%E2%80%93Savart_law) that gives the magnetic field of a current in a wire.
The [field verification](./results.md#independent-field-verification) uses it to evaluate the final wire path.

Gradient Efficiency
: The slope of the magnetic field generated by a coil, per Ampere of current, in T/m/A.


Stream Function
: A height map over the coil surface whose contour lines are the paths of the current. Each wire follows one contour, and
carries the height difference between neighbouring contours as its current. See [How It Works](./how_it_works_beginners.md).

Sensitivity Matrix
: A table of the magnetic field that each corner of the surface mesh contributes at each target point, per unit of
stream function. It turns the search for a coil into a linear problem.

Tikhonov Regularisation
: A penalty added to the search for the stream function, so that the solution wastes less power as heat. A larger factor
gives a more practical coil, and a less perfect field.

Contour Line
: A line of constant stream function value. Each contour line becomes one loop of wire.
